    FAQ
  
    What is the difference between CT, TAT and WT?
    CT is the clock time at which the process ends. TAT is the total time since it arrived. WT is the part of TAT spent waiting in the ready queue, so WT = TAT - BT.
    
  
    What is the convoy effect?
    In FCFS, short processes queue behind one long process and wait a long time, which raises the average waiting time.
    
  
    Which algorithm gives the smallest average waiting time?
    SRTF (and SJF when no preemption is allowed) is provably optimal, but it needs the burst times in advance and can starve long processes.
    
  
    How should the time quantum be chosen?
    If it is very large, Round Robin behaves like FCFS. If it is very small, context-switch overhead dominates. A common rule is to make about 80% of bursts shorter than the quantum.
    
  
    What is starvation, and how does MLFQ handle it?
    Starvation is when a process never gets the CPU. Real MLFQ systems use aging, which moves long-waiting processes up to a higher queue.
    
  
    Preemptive or non-preemptive?
    A preemptive scheduler can take the CPU away from a running process (SRTF, RR, MLFQ). A non-preemptive one lets it run until it finishes or blocks (FCFS, SJF).
    
  
    Why is the CPU sometimes idle?
    If no process has arrived yet, the CPU waits. The simulator shows this as a hatched "idle" block.
